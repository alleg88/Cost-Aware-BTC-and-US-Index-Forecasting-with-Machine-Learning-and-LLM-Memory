# Evaluation

The evaluation layer provides chronological blocking splits, walk-forward execution,
trade ledgers and predictive/economic metrics. Signals map down/flat/up to short/flat/long.
Net returns deduct the registered round-trip costs: 10 bps BTC, 2 bps USA500 and 3 bps
USATECH. Reported risk measures include Sharpe, Sortino and maximum drawdown.

Q2 2026 is read only through the frozen final protocol. BTC is confirmatory; index Q2 rows
are descriptive transport checks.
